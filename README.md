# CHEES.UP

Шахматный клуб в Telegram: партии с восемью ботами, разбор с тренером Филином, задачи, квесты и награды.
Открыть: https://kikorikkikorik76-png.github.io/chees_up/

## Озвучка тренера

Telegram не умеет читать текст вслух, поэтому реплики заранее записываются в mp3 по кусочкам
(`voice/<id>.mp3`), а приложение склеивает из них фразы.

**Записать (один раз):**

1. На GitHub открой этот репозиторий → вкладка **Actions**.
2. Слева выбери **«Озвучить тренера»** → кнопка **Run workflow** → ещё раз **Run workflow**.
3. Подожди, пока появится зелёная галочка. mp3 сами сохранятся в папку `voice`, и сайт обновится.
4. Открой приложение заново.

Голос — свободная нейросеть [Piper](https://github.com/OHF-Voice/piper1-gpl), русский голос `dmitri`
(можно выбрать `denis`). Чтобы сменить голос, запусти ещё раз с галочкой «Переозвучить».

**Свои записи:** замени любые файлы в `voice/` своими mp3 с теми же именами
(что в каком файле — в `voice/phrases.json`). Если mp3 ещё не генерировались, после загрузки своих выполни
`python3 tools/make_voice.py --manifest-only`, чтобы обновить список.

Если поменялись тексты реплик в `js/voice.js`: удали старые mp3 изменённых фраз или запусти с «Переозвучить».

## Что где лежит

| Файл | Что внутри |
|---|---|
| `index.html`, `css/style.css` | экраны и оформление |
| `js/engine.js`, `js/worker.js` | шахматный движок |
| `js/app.js` | доска, партии, разбор, редактор |
| `js/puzzle.js`, `js/puzzles.js` | экраны задач и сами задачи |
| `js/hub.js`, `js/meta.js` | главная, квесты, профиль; серии, уровни, награды |
| `js/art.js` | тренер Филин и значки |
| `js/voice.js` | тексты реплик и проигрыватель |

После изменений в файлах увеличь номер `?v=4` в `index.html` (и в `js/app.js`, `js/worker.js`),
чтобы телефоны не брали старую версию из кэша.

## Прогресс игрока

Хранится на устройстве и в облаке Telegram (CloudStorage). Монеты только игровые, платежей нет.

## Подключение к боту

В @BotFather: `/mybots` → бот → **Bot Settings** → **Menu Button** (или `/newapp`) и указать адрес выше.
Токен бота никуда в репозиторий класть не нужно.
