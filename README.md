# CHEES.UP

Шахматы в виде Telegram Mini App: боты, игра вдвоём, задачи, разбор партий и редактор позиций.
Весь сайт находится в `index.html`, сборка и сервер не нужны.

## Публикация через GitHub Pages

1. Создай на GitHub публичный репозиторий `chees_up`.
2. Загрузи в него `index.html`, `README.md` и `.nojekyll` (Add file → Upload files).
3. Открой Settings → Pages. Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`. Нажми Save.
4. Подожди пару минут. Адрес будет вида `https://ИМЯ.github.io/chees_up/`.

## Подключение к Telegram

1. Напиши [@BotFather](https://t.me/BotFather): `/newbot`, задай имя и username бота.
2. `/mybots` → выбери бота → **Bot Settings** → **Menu Button** → отправь адрес из GitHub Pages и название кнопки, например «Играть».
3. Открой своего бота и нажми кнопку меню.

Прямую ссылку вида `t.me/бот/приложение` можно создать командой `/newapp`.

**Токен бота никому не отправляй и не загружай в репозиторий.** Для этого приложения он в коде не нужен.

## Ограничения

- Прогресс хранится только на устройстве игрока.
- Онлайн-игры между людьми нет: для неё нужен сервер.
- Озвучка зависит от устройства и может не работать внутри Telegram.
